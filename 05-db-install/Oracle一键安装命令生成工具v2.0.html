三步完成安装

01
上传软件包
将 OracleShellInstall.sh 脚本和 Oracle 安装介质上传至服务器 /soft 目录
02
配置参数
在本页面选择安装模式，填写环境参数，实时生成安装命令
03
执行安装
复制生成的命令，在服务器 /soft 目录下以 root 用户执行即可
